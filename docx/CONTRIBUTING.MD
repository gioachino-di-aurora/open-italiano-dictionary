# 贡献指南

感谢参与 Open Italiano Dictionary。

Open Italiano Dictionary 是一个开放的中文—意大利语词典项目。项目欢迎任何人提交新的词条、补充释义、修正错误，以及报告词典中的问题。

## 1. 基本原则

本项目最重要的原则是：

> 工具可以自由替换，数据格式不能随意改变。

词典数据必须遵守项目规定的数据格式。

贡献者可以使用任何工具编辑、生成或检查数据，但最终提交的数据必须符合 `schema/FORMAT.md` 中规定的格式。

## 2. 可以贡献什么

欢迎提交：

- 新的意大利语词条
- 中文释义
- 词性信息
- 复数、变位等词形信息
- 动词助动词信息
- 固定搭配
- 词源或相关信息
- 词条之间的关联
- 对现有词条的错误修正
- 发现的重复词条
- 格式错误
- 其他有可靠依据的词典信息

## 3. 提交新词条

提交词条前，请确认：

1. 单词拼写正确。
2. 该词确实属于意大利语词汇，或者已经按照外来语规则进行声明。
3. 词性正确。
4. 中文释义准确。
5. 词形信息正确。
6. 不存在明显的重复词条。
7. 数据符合项目规定的格式。

如果词汇属于外来语，必须明确声明其外来语性质。

未声明的外来语词汇将被直接拒绝。

外来语的具体要求见：

`FOREIGN_WORDS.md`

## 4. 修改现有词条

如果发现现有词条存在错误，请优先提交修改建议，而不是直接删除原有内容。

请说明：

- 错误位置
- 当前内容
- 建议修改内容
- 修改依据

对于存在争议的内容，应保留原数据，并交由人工审核。

## 5. AI 审核

本项目可以使用 AI 协助进行词典质量检查。

AI 可以检查：

- 意大利语拼写
- 中文释义中的明显错误
- 词性
- 词形
- 重复词条
- 外来语声明
- 数据格式
- 明显的非意大利语内容

AI 不具有最终修改权。

AI 发现疑点时，应在词条后添加审核标记，并进入人工审核流程。

AI 不得在未经人工确认的情况下自行修改正式词典数据。

## 6. 审核

所有正式进入词典的数据都需要经过人工审核。

人工审核主要负责：

- 确认明显错误
- 判断 AI 提出的疑点
- 确认词条是否适合收录
- 处理重复词条
- 处理有争议的词义
- 确认外来语词条

人工审核不要求逐字重新编写词典。

## 7. 数据格式

请严格遵守：

`schema/FORMAT.md`

不要因为个人习惯自行改变字段名称、字段顺序或数据结构。

如果认为现有格式需要修改，请先提出格式修改建议，而不是直接在词典数据中使用新的格式。

## 8. Pull Request

提交 Pull Request 后，自动检查程序可能检查：

- Markdown 格式
- 必填字段
- 词性格式
- 重复词条
- 外来语声明
- 数据结构
- 其他项目规定

自动检查发现问题时，请根据检查结果修改提交内容。

最终是否合并由维护者决定。

## 9. Issue

如果不熟悉 Git 或 Pull Request，可以直接使用 GitHub Issue 提交：

- 新词条
- 错误报告
- 外来语
- 格式问题
- 其他建议

项目维护者可以将 Issue 中的信息转换为正式词典数据。

## 10. 不要提交

请不要提交：

- 明显错误的意大利语单词
- 未声明的外来语
- 无依据的词义
- 无法确认来源的信息
- 与现有词条完全重复的内容
- 与项目数据格式不兼容的内容
- 与项目无关的数据

感谢所有贡献者。
